# Nova Spear Swap

Mod Fabric (1.21.11) dodający klawisz "Spear Swap" w Ustawieniach -> Sterowanie.
Po przypisaniu klawisza: spear z ekwipunku jest przenoszony na slot 1, wybierany i od razu używany.

## Budowanie
1. Sprawdź wersje w gradle.properties na https://fabricmc.net/develop
2. `./gradlew build` (lub przez GitHub Actions)
3. Gotowy .jar: build/libs/nova-spearswap-1.0.0.jar
4. Wrzuć do mods/ razem z Fabric API.
